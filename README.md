# Лабораторная работа №3: Полиномы (многочлены) на базе полиморфных последовательностей

Демонстрация работы целевого АТД «Многочлен» (`Polynomial<T>`), построенного поверх полиморфных контейнеров из ЛР2 (`Sequence`, `ArraySequence`, `ListSequence`).  
Поддерживаются целые, вещественные и комплексные коэффициенты, а также операции сложения, умножения, композиции, дифференцирования, интегрирования, деления с остатком, НОД и многое другое.  
Реализовано в рамках курса `"Информатика (полиморфные абстрактные типы данных)"` (2 семестр) на основе варианта **№12 (Многочлен)**.

## Структура проекта

- **`Polynomial.h`** – объявление шаблонного класса `Polynomial<T>` (конструкторы, операторы, методы).
- **`PolynomialCore.h`** – реализация всех методов класса (включая `Normalize`, арифметику, доступ, `Evaluate`, `Compose`).
- **`PolynomialOperations.h`** – дополнительные алгоритмы: `Derivative`, `Integral`, `Pow`, `Shift`, `ReduceFront`, `Divide`, `GCD`.
- **`PolynomialUtils.h`** – вспомогательные функции: перегрузка `operator<<` для красивого вывода, метод `print()`.
- **`Exceptions.h`** – класс `PolynomialException` (обработка ошибок: выход за границы, деление на ноль, некорректные аргументы).
- **`tests.cpp` / `tests.h`** – модульные тесты для `int`, `double`, `std::complex<double>` на массиве и списке. Включает стресс‑тест 10M `append` и замеры времени.
- **`menu.cpp` / `menu.h`** – интерактивное консольное меню для работы с многочленами (создание, все операции, выбор контейнера Array/List, замена текущего многочлена).
- **`main.cpp`** – точка входа: при запуске без аргументов вызывает `runMenu()`, с аргументом `--test` запускает `runAllTests()`.
- **`Makefile`** – сборка проекта (флаги `-std=c++17 -Wall -Wextra -g -fsanitize=address -I. -I../lab2`).

## Функциональность класса Polynomial<T>
### Конструкторы и специальные методы
 - `Polynomial()` – нулевой многочлен 0 (хранится как [0]).
 - `Polynomial(T item)` – многочлен‑константа `item`.
 - `explicit Polynomial(Sequence<T>* coeffs)` – принимает готовую последовательность коэффициентов, нормализует.
 - Копирующий и перемещающий *конструкторы*, *деструктор*.
 - Операторы присваивания (копирующий и перемещающий).
 - Арифметические операторы
 - `+`, `-`, `*` (многочлен на многочлен), `*` (на скаляр).
 - Составные операторы: `+=`, `-=`, `*=` (для многочлена и скаляра).
 - `==`, `!=` – поэлементное сравнение.

## Базовые операции
 - `int Degree() const` – возвращает количество коэффициентов (после `Normalize`).
 - `T GetCoefficient(int index) const`, `void SetCoefficient(T item, int index)`.
 - `const T operator[](int index) const` – доступ для чтения.
 - `T Evaluate(const T& x) const` – значение в точке (схема *Горнера*).
 - `Polynomial<T> Compose(const Polynomial<T>& other) const` – композиция *P(Q(x))*.

## Дополнительные операции (вариант №12 и сверх него)
 - `Polynomial<T> Derivative() const` – *производная*.
 - `Polynomial<T> Integral() const` – неопределённый *интеграл* (константа C = 0).
 - `Polynomial<T> Pow(int n) const` – *возведение* *в* целую неотрицательную *степень* (линейное).
 - `Polynomial<T> Shift(int k) const` – *умножение* на x^k (добавление k нулей в начало).
 - `Polynomial<T> ReduceFront(int n = -1) const` – *удаление* ведущих нулей (до n штук или всех).
 - `std::pair<Polynomial<T>, Polynomial<T>> Divide(const Polynomial<T>& other) const` – *деление* с остатком.
 - `Polynomial<T> GCD(const Polynomial<T>& other) const` – *наибольший общий делитель* (алгоритм Евклида).

## Вспомогательные методы
 - `void Normalize()` – удаляет концевые нули (сохраняя хотя бы один элемент).
 - `const Sequence<T>* GetCoefficients() const` – доступ к сырой последовательности.
 - Красивый вывод через `operator<<` (формат: 3x^2 - 2x + 1).

## Модульные тесты (tests.cpp)
1. *Полное покрытие* всех публичных методов для типов `int`, `double`, `std::complex<double>` на двух контейнерах: `Array` и `List`.
2. Каждый блок тестов сопровождается *выводом в консоль* (✅ Конструкторы, ✅ Арифметика, и т.д.).
3. В конце для каждого типа и контейнера *выполняется стресс‑тест* – 10 миллионов append в пустую последовательность, и выводится *общее время*.
4. После прогона всех комбинаций печатается сводная *таблица производительности*, показывающая, во сколько раз *Array быстрее List*.

### Пример вывода сводки:

```text
========== PERFORMANCE SUMMARY ==========
Type                  Array (ms)   List (ms)       Faster
-------------------------------------------------------------------------
int                     258         1176        Array is 4.56x faster
double                  401         919         Array is 2.29x faster
complex<double>         1618        1729        Array is 1.07x faster
==========================================
```

 - Все тесты проходят *без утечек памяти* (проверено AddressSanitizer).

## Консольное меню (menu.cpp)
**Позволяет:**
1. *Выбрать* тип коэффициентов (`int` или `double`).
2. *Выбрать* тип контейнера для внутреннего хранения (`Array` или `List`).
3. *Создавать* *многочлены* (вручную, задавая степень и коэффициенты, или тестовый `[1,2,3]`).
4. *Переключаться* между созданными многочленами.
5. *Выполнять* все реализованные *операции* (`+`, `-`, `*`, `Evaluate`, `Compose`, `Derivative`, `Integral`, `Pow`, `Shift`, `ReduceFront`, `Divide`, `GCD`, *сравнение*, *доступ к коэффициентам*).
6. Для операций, возвращающих новый многочлен, предлагается *заменить* текущий на результат.
7. *Замерять* время выполнения операций (выводится в *миллисекундах*).
8. *Сравнивать* производительность `Array` и `List` на умножении многочленов *100‑й степени*.

## Особенности реализации
1. **Полиморфное хранилище** – `Polynomial<T>` содержит `Sequence<T>*`, что позволяет в рантайме выбирать `MutableArraySequence` или `MutableListSequence`. Все операции используют только интерфейс `Sequence`.
2. **Нормализация** – метод `Normalize()` *автоматически* вызывается после *операций*, порождающих ведущие нули (сложение, вычитание, умножение). Это гарантирует *каноническое* представление.
3. **Шаблонная универсальность** – код работает с *любым типом `T`*, поддерживающим `+`, `-`, `*`, `/`, `==`, `T(0)`, `T(1)`.
4. **Поддержка комплексных чисел** – благодаря использованию `std::complex<double>` без изменений в классе (требуется лишь явное приведение `int` к `T` в `Derivative` и `Integral`).
5. **Деление и НОД** – реализованы через *алгоритм деления столбиком* и *алгоритм Евклида* соответственно.
6. **Производительность** – стресс‑тест *10M `append`* наглядно демонстрирует преимущество динамического массива перед связным списком (в **2–4 раза** для числовых типов).
7. **Удобное меню** – возможность *управлять* несколькими многочленами, *заменять* текущий, *замерять* время операций.
